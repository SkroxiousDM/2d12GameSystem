# Rules audit: Phase 1 decisions

This file indexes the controlling decision records. The numbered files preserve the original document's wording, decision numbers and order.

## Reading the decisions

- Read the original date/source and reconciliation paragraphs at the beginning of the foundational-decisions file before using the records.
- Preserve the distinction between a selected ruling, its scoped source implementation, remaining reference work and deferred validation.
- Read each decision with its scope, exceptions, supersession statements and Playtest or verification notes.
- Original audit identifiers, residual-pass identifiers and decision-section numbers are distinct; do not treat them as interchangeable.
- File numbers identify document order, not new decision numbers or precedence.
- This structural partition makes no new rulings and does not close Phase 1.
